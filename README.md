# CodePixel Web — Premium Reels Promo Generator

একটি ছোট, সম্পূর্ণ কার্যকর অ্যাপ: **অডিও আপলোড করুন → ভিডিও তৈরি করুন → ভিডিও ডাউনলোড করুন**।

আপলোড করা বাংলা ভয়েসওভার অপরিবর্তিত থাকে; ভিডিওর দৈর্ঘ্য নির্ধারিত হয় আসল অডিওর
duration দিয়ে (ffprobe), এবং ৭৭টি দৃশ্যের মূল কাহিনি-ক্রম রাখা হয়েছে — প্রতিটি
দৃশ্যের ভিজ্যুয়াল সম্পূর্ণ নতুনভাবে ডিজাইন করা (স্টোরফ্রন্ট, প্রোডাক্ট, কার্ট→চেকআউট,
অ্যাডমিন প্যানেল, অর্ডার, কুরিয়ার, পেমেন্ট, রিটার্গেটিং, অফার ও শেষ কার্ড)।

**আউটপুট:** `1080 × 1920` · `30 fps` · `H.264 MP4 + AAC` → `output/CodePixel-Web-Promo-Reels.mp4`

## চালানো

```bash
npm install          # @napi-rs/canvas + ffmpeg/ffprobe static binaries
npm start            # http://localhost:3000
```

ব্রাউজারে খুলে অডিও (MP3/WAV/M4A/AAC) আপলোড করুন → **ভিডিও তৈরি করুন** → শেষ হলে
**ভিডিও ডাউনলোড করুন**। রেন্ডার শেষে ফাইলটি `output/CodePixel-Web-Promo-Reels.mp4`।

CLI দিয়েও রেন্ডার করা যায়:

```bash
node src/render/render.mjs --audio assets/voiceover/voiceover.m4a \
  --out output/CodePixel-Web-Promo-Reels.mp4
```

একটি নির্দিষ্ট মুহূর্তের ফ্রেম দেখতে:

```bash
node src/render/render.mjs --still 451.2 --png output/stills/frame.png
node tools/qa-frames.mjs            # সব ৭৭ সিনের QA contact sheet
```

## ভয়েসওভার কোথায় রাখবেন

```
assets/voiceover/voiceover.m4a      # অথবা .mp3 / .wav
```

অ্যাপ থেকে আপলোড করলে ফাইল যায় `uploads/<id>/voiceover.<ext>`-এ। কোনো অবস্থাতেই
অডিও সম্পাদনা, ক্রপ, স্পিড-চেঞ্জ বা রি-এনকোড (কেবল AAC মাক্স) করা হয় না।

### টাইমিং

মূল প্ল্যানের ৩৪৩ সেকেন্ডের সোর্স টাইমকোড আর ০৮:১২.৩৫৬ (৪৯২.৩৫৬s) আউটপুট
অনুপাত (×1.43544) দিয়ে দৃশ্য-সীমা হিসাব হয়, তারপর আপলোড করা অডিওর আসল দৈর্ঘ্যে
আনুপাতিকভাবে স্কেল হয় এবং (সম্ভব হলে) `silencedetect` দিয়ে পাওয়া স্বাভাবিক
পজ-এ স্ন্যাপ করে। ফ্রেম নম্বর প্রতিটি সীমার জন্য আলাদা `round(t × 30)` —
ক্রমবর্ধমান রাউন্ডিং ড্রিফট নেই। শেষ ফ্রেমে ভিডিও কভার করে সম্পূর্ণ অডিও।

## সীমাবদ্ধতা (সৎভাবে)

- এই পরিবেশে Chrome/Chromium নেই, তাই Remotion-এর ব্রাউজার-রেন্ডার ব্যবহার করা হয়নি।
  একই ডিটারমিনিস্টিক আউটপুট Skia canvas + ffmpeg দিয়ে তৈরি হয়।
- `watchbd.vercel.app` ও `demoadmin-jet.vercel.app` — দুটোরই কাঠামো/ভাষা/হায়ারার্কি
  অনুসরণ করা হয়েছে, তবে এখান থেকে স্ক্রিনশট নেওয়া সম্ভব নয়; তাই একই স্টাইলে
  নতুন, পরিষ্কার ডেমো UI আঁকা হয়েছে (ফিকশনাল ব্র্যান্ড `AURUM`, নমুনা ডেটা)।
  কোনো ভুয়া রিভিউ, রেটিং, বিক্রির পরিসংখ্যান বা প্রতিশ্রুতি নেই।
- অপশনাল ফিচার (কুরিয়ার ইন্টিগ্রেশন, পেমেন্ট গেটওয়ে, মেটা পিক্সেল, টেলিগ্রাম/ইমেইল,
  ফ্রি হোস্টিং, ল্যান্ডিং পেজের সংখ্যা) সবই "ইন্টিগ্রেশন/স্কোপ সাপেক্ষে" হিসেবে দেখানো হয়।
- ফন্ট: Noto Sans Bengali + Inter (SIL OFL) — `assets/fonts/`।
