# MIQA — standing video CTA preference

User instruction, 2026-11-03; applies to future videos unless explicitly revised:

- Do not display a website name, domain, URL or link in the video.
- Do not speak a website name, domain, URL or link in the narration.
- Use this ordering CTA, in on-screen copy and narration where applicable:

  **অর্ডার করতে ক্লিক করুন অর্ডার বাটনে।**

This supersedes earlier website-address / visit-the-website CTA directions for future videos. Do not fabricate an interactive button inside the video; the wording refers to the order button on the publishing platform. This instruction alone does not request re-exporting previously delivered videos or changing website/application code.
