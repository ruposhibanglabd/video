# Motion Graphics Guidelines

Motion graphics are a **major creative feature** of every project — modern,
sophisticated, professionally designed.

## Approved technique vocabulary

- Dynamic infographic animation · data visualization · number counters
- Kinetic typography (see `TYPOGRAPHY_GUIDELINES.md`)
- Animated labels & scientific callouts
- 2D shape animation · refined 3D graphic elements
- Map animations · timeline animations · animated diagrams
- Parallax compositions · layered graphic movement
- Particle systems (tasteful, purposeful)
- Mask transitions · animated clipping
- Camera-driven graphics · animated icons · information cards · elegant reveals

## Motion principles (always)

Timing · spacing · **easing** · anticipation · follow-through · overlapping action ·
secondary motion · visual hierarchy · motion continuity.

## Forbidden

Random bouncing · unnecessary spinning · excessive shaking · cheap glow · generic preset
effects · repetitive animations · movement with no storytelling purpose.

## The test

Every motion graphic must contribute to **storytelling, understanding or visual
beauty**. If it does none of the three, cut it.
