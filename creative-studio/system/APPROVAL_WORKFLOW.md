# Approval Workflow — Two Phases, Always

> **Never start final production before the user's explicit approval.**
> User-controlled decisions: **1) topic · 2) voice · 3) production approval.**

---

## PHASE 1 — Research & production plan (triggered by any topic)

| Step | Action | Output |
|---|---|---|
| 1 | Understand the topic | Category, audience, central message, storytelling style, research needs, visual opportunities |
| 2 | Conduct research | Verified information + references, saved to `projects/<name>/RESEARCH.md` |
| 3 | Creative concept | Title, concept, opening hook, narrative direction, emotional tone, visual style, color direction, typography direction, motion style, audio atmosphere |
| 4 | Script | Complete natural Bengali narration — clear, correct, well-paced, right duration |
| 5 | Storyboard | Every scene per `SCENE_PLANNING_TEMPLATE.md` |
| 6 | Master timeline | Approximate timestamps now; precise timeline only after VO is generated |
| 7 | Voice options | 3–5 suitable profiles with previews where possible → **wait for user selection** |
| 8 | Production resources | Images, footage, generated assets, motion graphics, fonts, audio, techniques, tools |
| 9 | Present complete plan | **Topic-specific**, never generic |
| 10 | Request approval | Stop and wait |

## PHASE 2 — Production (only after explicit approval)

1. Finalize selected voice → 2. produce narration → 3. generate/collect visual assets →
4. build scene backgrounds → 5. create animations → 6. design typography → 7. build
motion graphics → 8. assemble master timeline → 9. synchronize narration & text →
10. place sound effects → 11. background audio → 12. color grade → 13. edit & composite
every scene → 14. add personal signature → 15. review the render → 16. correct errors →
17. export final MP4 → 18. upload deliverables to Google Drive (verified) →
19. update production records (`projects/<name>/`, `CHANGELOG.md`, voice history).

**Do not skip quality control** (`../production/QUALITY_CONTROL.md`).

If a major creative change becomes necessary after approval, **inform the user before**
deviating from the agreed concept.

## Deliverables (per approved project)

Final MP4 · thumbnail · Bengali script · scene storyboard · master timeline · subtitle
file · voiceover file · generated images · key animation assets · research references ·
project files (when supported) — uploaded to the correct Drive folders with verified
links, organized for future editing.
