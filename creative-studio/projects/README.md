# Projects

One folder per production: `projects/<slugified-topic-name>/`

```
projects/<project-name>/
    RESEARCH.md          # sources, verified facts, uncertainties
    SCRIPT.md            # approved Bengali narration
    STORYBOARD.md        # scene cards (see production/SCENE_PLANNING_TEMPLATE.md)
    PRODUCTION_PLAN.md   # the approved plan + creative concept
    ASSET_MANIFEST.md    # every image/clip/audio asset + source + status
    VOICE_SETTINGS.md    # selected voice profile + settings
    TIMELINE.md          # approx. → final master timeline + audio lanes
    PRODUCTION_LOG.md    # dated work log
    FINAL_DELIVERY.md    # deliverables + verified Drive links
```

## Lifecycle

`planning` → `awaiting-approval` → `approved` → `in-production` → `qc` → `delivered`

State lives at the top of each project's `PRODUCTION_LOG.md`.

## Rules

- A project folder is created at the **start of Phase 1** (planning documents may be
  saved during planning).
- Nothing enters `09 - Final Videos/` on Drive before approval + QC.
- Deliverable filenames follow `system/VIDEO_TECHNICAL_STANDARDS.md` §4.
