# Signature Guidelines

Every final video carries the creator signature:

## Specification

| Property | Rule |
|---|---|
| Text | **Abdur Rahman Nayeem** |
| Style | English handwritten signature-style type treatment |
| Character | Small · elegant · premium · minimal · professional · subtle · consistent |
| Placement | Bottom-right preferred (or another suitable corner), always inside the mobile-safe area |
| Prominence | Low — a professional creator's signature, never a large watermark or ad logo |
| Animation | A tasteful signature animation only when appropriate |
| Frequency | Not necessarily every scene — omit where it harms composition |

## Hard rules

- Never obstructs subtitles, important information or religious text.
- Never competes with the main content.
- Identical treatment across projects once a signature style is approved (the approved
  style will be recorded here after the first project).
