# Production Workflow — End to End

```
TOPIC (user)
  → PHASE 1: research → concept → script → storyboard → approx. timeline
             → voice options → resource plan → PROPOSAL
  → USER APPROVAL (+ voice selection)
  → PHASE 2: narration → assets → scenes → typography → motion graphics
             → master timeline (from real audio) → sync → SFX/music → grade
             → edit/composite → signature → QC review → fixes
  → EXPORT final MP4 (+ thumbnail, subtitles)
  → DELIVER to Google Drive (verified) → UPDATE records
```

## Phase gates

| Gate | Condition to pass |
|---|---|
| Planning complete | Steps 1–9 of `../system/APPROVAL_WORKFLOW.md` documented in `../projects/<name>/` |
| Production start | Explicit user approval + voice selected |
| Delivery | QC checklist passed (`QUALITY_CONTROL.md`), uploads verified |
