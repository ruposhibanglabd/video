# Quality Control — Non-Negotiable Standards

Run before every delivery. Any unchecked box blocks release.

## Visual
- [ ] Premium cinematography; every scene compositionally designed
- [ ] Backgrounds match the narration at every moment
- [ ] Consistent color grade across all scenes; no crushed blacks, no over-saturation
- [ ] High-quality visuals (realistic or intentionally stylized — never random)
- [ ] Native vertical composition; safe areas respected

## Typography
- [ ] Top-tier animated typography; strong hierarchy
- [ ] Bengali text correct — spelling, conjuncts (যুক্তাক্ষর), shaping all verified
- [ ] Text readable on every background; never hidden by platform UI
- [ ] Text reveals synchronized to narration; nothing cut off too early

## Motion
- [ ] Professional easing; natural movement
- [ ] Sophisticated transitions; no generic/repetitive presets
- [ ] Every motion element serves story, understanding or beauty

## Audio
- [ ] Clear voiceover; perfect sync
- [ ] Balanced music; consistent loudness (≈ −14 LUFS)
- [ ] SFX only on real visual events; intentional silence where designed

## Story
- [ ] Strong opening hook · accurate information · meaningful conclusion
- [ ] Facts verified; Islamic content follows `ISLAMIC_CONTENT_GUIDELINES.md`

## Branding
- [ ] Small elegant signature present and unobstructed
- [ ] Photo (if used) authorized and appropriate

## Delivery
- [ ] Final MP4 spec-correct (1080×1920, fps, H.264/H.265, AAC)
- [ ] Full deliverable set uploaded to correct Drive folders and **verified**
- [ ] `projects/<name>/` records, `CHANGELOG.md`, voice history updated

## Process
- [ ] Rendered video actually reviewed (frame QA / contact sheet where useful)
- [ ] Errors corrected and re-rendered before delivery
