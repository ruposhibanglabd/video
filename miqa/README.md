# MIQA — ভিডিও বিজ্ঞাপনের "মেমোরি"

> **Beyond Time, Beyond Style.**
> এখানে MIQA-এর Reels বিজ্ঞাপন বানানোর সব নির্দেশ, সিদ্ধান্ত আর ডিজাইন গাইড সেভ করা আছে। নতুন চ্যাটে কাজ শুরুর আগে এজেন্ট এগুলো পড়ে নেবে।

**অবস্থা (২ নভেম্বর ২০২৬):** প্রস্তুতি চলছে। আপনার কথামতো এখনো কোনো ভিডিও বানানো হয়নি।

## আপনি যা পাঠাবেন → আমি যা দেব
| আপনি পাঠাবেন | আমি দেব |
|---|---|
| ঘড়ির আসল ছবি (সব দিক থেকে), নাম, দাম, ফিচার, কালার | 4K ভিডিও (2160×3840 MP4) + মোবাইল কপি (1080×1920) |
| প্রথমবার: MIQA লোগো (PNG/SVG) | কভার, বাংলা ভয়েসওভার, নিজের বানানো মিউজিক |
| বাকি যা লাগবে, আমি প্রশ্ন করে জেনে নেব | Facebook Primary Text, Headline, Description, QC রিপোর্ট — সব GitHub-এ, ডাউনলোড লিংকসহ |
