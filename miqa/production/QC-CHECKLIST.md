## খ. টেকনিক্যাল চেক
- **কোডেক:** H.264 High, yuv420p, 30 fps CFR, BT.709 ট্যাগ; অডিও AAC স্টেরিও 48 kHz।
- **ফাইল:** `+faststart` আছে, edit list নেই; 4K ফাইল < 100 MB।
- **শব্দ নিয়ম:** কোনো ফুটেজ বা মিউজিক থার্ড-পার্টির নয়; `CREDITS.md` লেখা হয়েছে।
- **ঝুঁকি:** ট্রেডমার্ক বা দাবি নিয়ে কোনো খোলা প্রশ্ন বাকি নেই।

```bash
$FP -v error -show_entries format=duration,size,bit_rate:stream=codec_name,profile,width,height,r_frame_rate,pix_fmt,color_space,channels,sample_rate -of json OUT.mp4
$FF -i OUT.mp4 -vf cropdetect=24:16:0 -frames:v 300 -f null - 2>&1 | tail -3      # black bars
$FF -i OUT.mp4 -af ebur128=peak=true -f null - 2>&1 | tail -12                   # loudness
$FF -y -i OUT.mp4 -vf "fps=1,scale=270:-1,tile=8x6" -frames:v 1 qc/contact.jpg     # contact sheet
python3 -c "d=open('OUT.mp4','rb').read(); print('elst' in str(d[:4000000]))"      # must be False
```
