# MIQA · “Daylight” — মেয়েদের সব সেটের স্ট্যান্ডার্ড থিম

> **স্ট্যাটাস: বাধ্যতামূলক (locked).** ২০২৬-১১-০৮-এ সেট D-তে অনুমোদিত।
> এরপর মেয়েদের (মহিলাদের) যত সেট আসবে — সেট C, সেট B, নতুন যেকোনো সেট —
> **সবগুলো এই থিমে, এই রেসিপিতেই** তৈরি হবে। ছেলেদের/ইউনিসেক্স সেটেও ব্যবহার করা যাবে,
> শুধু টাইপের নাম আর ছবি বদলাবে।

---

## কেন এই থিম (সমস্যাটা কী ছিল)

গাঢ় plum/rosewood স্টেজে দেখতে দামি লাগলেও **ফোনে ঘড়ি চেনা যাচ্ছিল না**:
কালো ব্রেসলেট ব্যাকগ্রাউন্ডে মিশে যেত, আর ওয়াল-অফ-ওয়াচ লেআউটে প্রতিটি ডায়াল
ছিল মাত্র ~৫০ পিক্সেল। ক্লায়েন্টের অভিযোগ ছিল ঠিক এটাই — “ঘড়িগুলো ঠিক মতো
অ্যাডে লাগছে না, স্পষ্ট বোঝা যায় না”।

Daylight থিমের একটাই নিয়ম: **ঘড়ির ডায়াল ছবির সবচেয়ে উজ্জ্বল, সবচেয়ে শার্প,
সবচেয়ে বড় জিনিস।**

|---|---|---|

| স্টেজ — মাঝে | `#FBF3E9` | পণ্যের পেছনের উষ্ণ আইভরি |

| টাইপ — মূল | `#2B1118` (deep plum ink) | সেটের নাম, দামের নিচের লাইন |
| টাইপ — সেকেন্ডারি | `rgba(43,17,24,0.70)` | ছোট নোট |
| টাইপ — এক্সেন্ট | `#8E5F2E` → `#C08A4E` → `#77501F` (গ্রেডিয়েন্ট) | ট্যাগলাইন, দাম, আইব্রো |
| CTA পিল | `rgba(43,17,24,0.95)` + টেক্সট `#FFF9F1` | ক্যাশ অন ডেলিভারি |
| হাইলাইট | `rgba(255,250,242,0.85)` হ্যালো | গাঢ় টাইপের পেছনে |

> সেট-ভেদে **এক্সেন্ট গ্রেডিয়েন্ট** একটু বদলানো যাবে (সেট C-তে সামান্য গোলাপি-সোনালি),
> কিন্তু স্টেজ কখনো অন্ধকার হবে না, আর টাইপ কখনো সাদা-অন-কালো হবে না।

## ২. টাইপোগ্রাফি

- বাংলা: **Hind Siliguri** — নাম `HindB` (Bold), সাব-লাইন `HindSB` (SemiBold), নোট `HindM`
- ইংরেজি ওয়ার্ডমার্ক: **Cinzel Medium** (`MIQA`), লেটার-স্পেসিং শুধু ল্যাটিনে
- বাংলায় `letterSpacing` **কখনো নয়** — যুক্তাক্ষর ভেঙে যায়
- হায়ারার্কি: নাম ৯৬–১০৮px · দাম ১১৮–১৫০px · সাব-লাইন ৩৪–৪২px · নোট ২৯–৩৩px
- গাঢ় টাইপের পেছনে সবসময় **আইভরি হ্যালো** (shadow blur ২২–৩০, রঙ `#FFFAF2`) —
  ফটোর ওপরেও পড়া যায়

## ৩. ফটোগ্রাফি (প্লেট)

প্রতি সেটে **৮টি প্লেট**, ১০২৪², সব একই স্টুডিও-সেটআপে:

| # | শট | কেন |
|---|---|---|
| p01–p0N | প্রতিটি রঙের **হিরো** — ঘড়ি সোজা, ডায়াল ক্যামেরার দিকে | রঙ চেনার জন্য |
| p0N+1 | **লাইনআপ** — সব রঙ এক সারিতে | রেঞ্জ এক নজরে |
| p0N+2 | **হাতে-পরা** | স্কেল + লাইফস্টাইল |
| p0N+3 | **ম্যাক্রো** — ডায়াল/বেজেল | কারিগরি বিশ্বাস |
| p0N+4 | **গিফট বক্স** | উপহার-মার্কেট |

প্লেটের নিয়ম:
- ব্যাকগ্রাউন্ড **উষ্ণ আইভরি/শ্যাম্পেন সিল্ক**, হাই-কি সফট ডে-লাইট উপরে-বাঁ থেকে
- ঘড়ি ফ্রেমের ~৭৫% উচ্চতা, চারপাশে **যথেষ্ট ফাঁকা জায়গা** (টাইপ বসানোর জন্য)
- কেস, ডায়াল, ডায়ালের লেখা, কাঁটা, ব্রেসলেট, রঙ — **হুবহু অপরিবর্তিত**
- কোনো প্রপ, টেক্সট, লোগো ওভারলে, ওয়াটারমার্ক, বর্ডার নয়
- ওয়েবসাইটের পুরোনো ছবি ব্যবহার নয় — নতুন রেন্ডার

## ৪. ভিডিওর ছাঁচ (~৫৫–৬০ সে., ১০৮০×১৯২০, ৩০fps)

| সময় | দৃশ্য | পর্দায় |
|---|---|---|
| ০.০–৩.৫ সে | **Hook** | সব রঙ এক সারিতে (লাইনআপ) + ওয়ার্ডমার্ক + নাম + `৳…` |
| ৩.৫–… | **প্রতি রঙ ৩.৭–৫ সে** | এক ফ্রেমে এক ঘড়ি (বড়), নিচে নাম + “ডিজাইন-শব্দ” |
| … | **ম্যাক্রো** | বেজেল/ক্রিস্টাল ক্লোজ-আপ |
| … | **হাতে-পরা** | ওয়াটার রেজিস্ট্যান্স (শুধু ক্লায়েন্ট দিলে) |
| … | **গিফট বক্স** | উপহারের কোণ |
| … | **৫% pledge** | টাইপ-কার্ড, আইভরি স্টেজে |
| … | **৭ দিনের রিপ্লেসমেন্ট** | টাইপ-কার্ড |
| শেষ ~৫ সে | **CTA** | লাইনআপ/গ্রিড + দাম + ফিচার + COD পিল |

Motion নিয়ম (ক্লায়েন্টের শর্ত — ভাঙা যাবে না):
- প্রোডাক্ট শুধু **ডান → বাঁ** হার্ড-এজ স্লাইড
- **কোনো ক্রসফেড/ফেড/ফ্ল্যাশ নেই**, স্পার্কল স্প্রাইট নেই
- এক ফ্রেমে এক আইডিয়া; টাইপ কখনো ঘড়ির গায়ে নয়
- প্রতি ঘড়িতে ৪–৫ সে

## ১০. ওয়েবসাইট প্রোডাক্ট ছবি

সেট F থেকে নতুন ফরম্যাট — একই Daylight স্টেজে সাইটের জন্য ক্যাটালগ ছবি।

| ফাইল | কী |
|---|---|
| `<slug>_main.jpg` | পুরো ঘড়ি, সোজা সামনে থেকে — প্রোডাক্ট কার্ড/প্রধান ছবি |
| `<slug>_detail.jpg` | কেস + ডায়াল ম্যাক্রো (বড় ১২, মার্কার, হাতা, স্টোন) |
| `<slug>_wrist.jpg` | হাতে পরা লাইফস্টাইল |
| `set-x_shared_group.jpg` | সব রঙ এক সারিতে |
| `set-x_shared_gift.jpg` | খোলা গিফট বক্স |

নিয়ম:
- **১৬০০×১৬০০**, sRGB JPEG q92 (প্রতি ফাইল ≈ ২০০–৪০০ KB); `thumbs/`-এ ৬০০×৬০০ q82
- প্লেট **২× lanczos আপস্কেল + unsharp** (`work/uw/`) — সোর্স প্লেট ৮৯৬×১১৯৫, তাই
  ওয়েবসাইট সাইজে নরম হয়ে যায়; ২× না করলে ডায়ালের অক্ষর ঝাপসা
- ব্যাকগ্রাউন্ড = ওই প্লেটেরই blurred কপি + Daylight গ্লেজ → ফ্ল্যাট গ্রেডিয়েন্টের
  বদলে আসল ফটো-টেক্সচার, তবু পুরো প্যাক একই রঙে
- লাইফস্টাইল ছবি **full-bleed cover** — কম্পোজিট করলে সিম/সেঁध দেখা যায়, তাই নয়
- `_detail`-এ রিফ্লেকশন বা ফাঁকা নিচ আসলে `bottomFade()`
- **লেখা নেই** — URL/ফোন/ডিসকাউন্ট/লোগো/দাম কিছুই না (দাম সাইটের টেক্সটে)
- ঘড়ির কেস/ডায়াল/স্টোন/রঙ **হুবহু** — শুধু ক্রপ, রিসাইজ, হালকা শার্পেন

রিবিল্ড:

```bash
mkdir -p miqa/products/<set>/work/uw
for f in miqa/products/<set>/plates/*.png; do
  convert "$f" -filter Lanczos -resize 200% -unsharp 0x1+0.7+0.02 \
    "miqa/products/<set>/work/uw/$(basename "$f")"
done
node miqa/products/<set>/web_images_f.mjs     # ১৭টি ছবি
node miqa/products/<set>/web_sheet_f.mjs      # CONTACT-SHEET-WEBSITE.jpg
```
