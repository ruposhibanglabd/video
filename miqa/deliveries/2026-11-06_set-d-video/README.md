# সেট D — ভিডিও (MIQA “ভেলোরা”) · প্রিভিউ

মেয়েদের স্পেশাল কালেকশন — **ভেলোরা** · ১৪টি ঘড়ি · **৳৩৯৯**
কণ্ঠ: **voice-01** (নারী, bn-BD — নমুনা ১, ক্লায়েন্ট বেছেছেন)

## এই টার্নে কী হলো

- কালেকশনের নাম ফাইনাল: **ভেলোরা (Velora)** — `MIQA · ভেলোরা · মেয়েদের স্পেশাল কালেকশন`
- মোশন প্লান: একটার পর একটা ছবি **ডান থেকে বামে স্লাইড** হয়ে মাঝখানে আসে,
  আগেরটা বামে ঠেলে বের করে দেয়; প্রতিটি ঘড়ির নাম সাথে আসে।
  প্রতি ঘড়িতে **৫টি লুক** (প্রাইমারি → হাতে-পরা → কোণ → ডায়াল ক্লোজ-আপ → স্টাইলড),
  তাই কণ্ঠ বলতে বলতেই ছবি বদলাতে থাকে।
- ভয়েসওভারের প্রথম ১০টি লাইন রেকর্ড (এই টার্নের TTS সীমা ১০), আসল স্লাইড-ট্র্যাক
  আর স্কোর দিয়ে **২৫.২ সেকেন্ডের প্রিভিউ** (ইন্ট্রো + ঘড়ি ০১–০৩) রেন্ডার করা।
