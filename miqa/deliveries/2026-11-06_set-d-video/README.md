## মোশন (v2 — ফ্ল্যাশ বন্ধ)

- ঘড়ি বদল এখন **হার্ড স্লাইড**: নতুন কার্ড ডান থেকে ঢুকে আগেরটাকে বাঁয়ে ঠেলে
  দেয় (০.৬২ সে.), সিমে নরম ছায়া — **কোনো ক্রসফেড/মিক্স নেই**, তাই ঝলক নেই
- মাঝপথের হাতে-পরা/ম্যাক্রো ইনসার্ট **বাদ** (ঐটাই ফ্ল্যাশের মতো লাগছিল)

- নাম-কার্ড কার্ড থামার **পরে** ঢোকে
