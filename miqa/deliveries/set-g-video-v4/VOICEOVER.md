- **স্টেজ:** `#FAF9F6 → #F1EEE8 → #E2DED7` উল্লম্ব গ্রেডিয়েন্ট + উপরে-বাঁয়ে ঠান্ডা
  সফট কী + নিচে-ডানে ঠান্ডা ছায়া; গ্রেন σ≈১.৪; ভিনিয়েট ≤ ১৬%
- **টাইপ:** AnekBangla ExtraBold (ডিসপ্লে ৫৬–৮৮), AnekBangla SemiBold (সাব-লাইন),
  HindSiliguri (বডি), Montserrat (ইংরেজি লেবেল), Cinzel (wordmark); দাম AnekBangla
  ExtraBold + ব্রাস গ্রেডিয়েন্ট `#83642C → #C9A45C → #775A26`
- **প্লেট:** ক্লায়েন্টের আসল স্টুডিও ছবি, রঙ/ধাতু **অপরিবর্তিত**; ম্যাটে ফেদার + রেডিয়াল
  ফ্যালঅফ, নিচে হালকা কনট্যাক্ট শ্যাডো — সাদা চারকোনা বোঝা যায় না
- **প্রতিটি দৃশ্যের নিজস্ব জমিন:** ডায়াল কার্ডে ঠান্ডা গ্রাফাইট ওয়াশ, ওয়াটার কার্ডে
  নিচ থেকে নীল-ধূসর পুল, CTA-তে একই ঠান্ডা পুল
- **মোশন:** ডান→বাঁ হার্ড-এজ স্লাইড ০.৫ সে., কার্ডের ভেতরে ২% পুশ-ইন,
  **কোনো ফেড/ক্রসফেড/ফ্ল্যাশ নেই**
- **অডিও:** ১০০ BPM, Am–F–C–G প্যাড + গভীর বেস পালস + পিয়ানো মোটিফ + টিক;
