# Set H — website image pack (v8)

Rebuilt 8 Nov from the client's eight reference photos.

## What was wrong before, and what changed

| | old pack | this pack |
|---|---|---|
| bracelet | five-link Jubilee | **Oyster flat three-link**, gold centre link |
| hour markers | gold bars / baguettes | **square gold settings, one diamond each** |
| day window | missing or at the very top of the dial | **crown → ROLEX → day window → OYSTER PERPETUAL** |
| gold | neon yellow (R−B +113, sat 64%) | **soft champagne, matched to the reference (R−B +74.5, sat 40%)** |
| stage | warm beige | **cool steel-white `#F7F9FB → #D3DBE2`** |
| props | box, pillow, plastic film | **none — bare metal, empty corners** |

## Specs

- `1600 × 1600` px, sRGB, JPEG q92
- `thumbs/` — `600 × 600` px, JPEG q82
- every colour shot at `_1_main` shows the **whole watch**, nothing cropped
- shared stage so all seven read as one set under one light

## Colour order

1 green · 2 champagne (full gold) · 3 black · 4 silver · 5 blue · 6 red · 7 black steel (PVD)

`_2_angle` is a case/crown crop, `_3_dial` a dial macro, `_4_bracelet` a bracelet macro —
all derived from the same corrected plate, so the design never drifts between shots.
