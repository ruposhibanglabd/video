## পদ্ধতি (নতুন, সেট B-এর মানে)

আপনার ফটো রেফারেন্স হিসেবে দিয়ে AI ঘড়িটাকে স্টুডিও সেটে নতুন করে দাঁড় করায়,
আমি সেটাকে ২০০০×২০০০-এ ফিনিশ করি। রেফারেন্সে যা যা আছে তার সবই যাচাই করা হয়:
কেসের আটকোণ, XII, ডায়ালের লেখা (FIYOTA / TRUE WORTH), ডট মার্কার, কাঁটা, ক্রাউন,
আর হার্ট-ক্রিস্টাল + রোজ-গোল্ড হার্ট লিংকের চেন।
