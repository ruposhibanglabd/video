## নিয়ম মেনে যা করা হয়েছে

- **ঘড়ির প্রতিটি পিক্সেল ক্লায়েন্টের ছবি থেকেই** — AI দিয়ে ঘড়ি আঁকা হয়নি, আকার/রঙ/চেন বদলানো হয়নি।
- শুধু ফোন-ক্যামেরার রঙের আভা ঠিক করা হয়েছে (সাদা বালিশকে রেফারেন্স ধরে), আর হালকা শার্পেন।
- কাটআউটের কিনারার সাদা আভা সরানো হয়েছে; চেনের ফাঁক অটুট।
- ব্যাকগ্রাউন্ড সব ছবিতে একই Blush Mist, আলো ওপর-বাঁ দিক থেকে, কন্ট্যাক্ট + নরম ড্রপ শ্যাডো।
- প্রাইমারির ওপরের দুই কোণা ফাঁকা (ওয়েবসাইটের ব্যাজের জন্য)।
- **কোনো দাম, URL, ফোন, ছাড় বা অপ্রমাণিত দাবি নেই।**
