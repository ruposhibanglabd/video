`https://github.com/ruposhibanglabd/video/raw/main/miqa/deliveries/<folder>/<file>.mp4`
main-এ মেশানোর আগে `main`-এর জায়গায় ব্রাঞ্চের নাম বসাতে হবে।

**কিছু সীমা:**
- GitHub-এ প্রতিটি ফাইল ১০০ MB-এর কম হতে হবে। তাই 4K ফাইল সাইজ মেপে এনকোড করা হয় ([RUNBOOK §৮](../production/RUNBOOK.md))।
- Facebook আর Instagram ভিডিও দেখায় সর্বোচ্চ প্রায় 1080–1440p পর্যন্ত। 4K মাস্টার আপলোড করলে Facebook নিজেই সেটা ছোট করে নেয়, আর মূল কপি সর্বোচ্চ কোয়ালিটিতে আপনার কাছে থেকে যায়।
- অনেক ভিডিও জমলে রিপোজিটরি বড় হয়ে যাবে। তখন পুরনো ডেলিভারিগুলো আলাদা আর্কাইভ রিপোতে সরানো যাবে।

## ওয়েবসাইটের ছবি — সম্পূর্ণ রিডিজাইন V2
বর্তমান ফোল্ডার: `deliveries/<set>/<product>/redesign-v2/website-images/`। পুরোনো সেটে ফাইল রেখে নতুন রিভিশন আলাদা রাখা হয়, যাতে সংস্করণ মিশে না যায়। ([নির্দেশিকা](../creative/PRODUCT-IMAGES-GUIDE.md))

| ফাইল | কী |
|---|---|
| `<slug>_01_primary.jpg` | সম্পূর্ণ নতুন জেনারেটেড প্রাইমারি; বাইরের লেখা/পিল/ইনসেট নেই |
| `<slug>_02_on-wrist.jpg` | হাতে পরা |
| `<slug>_03_angle.jpg` | কোণ থেকে |
| `<slug>_04_<feature>.jpg` | ফিচারের নতুন ম্যাক্রো দৃশ্য |
| `<slug>_05_box.jpg` / `_05_colors.jpg` / `_05_styled.jpg` | বক্স / সব রঙ / স্টাইলড |
| `<slug>_website-images.zip` | সব ছবি একসাথে |
| `README.md`, `QC-REPORT.md`, `manifest.json` | ডাউনলোড, যাচাই ও AI ভিজ্যুয়ালাইজেশনের সীমা |

- সব ছবি ২০০০×২০০০ ডেলিভারি, JPG (sRGB)। নেটিভ জেনারেশন মাপ manifest-এ আলাদা করে লিখতে হবে।
- ঘড়ি কেটে বসানো, আরোপিত ছায়া ও ফিচার-চিপ নিষিদ্ধ। সম্পূর্ণ দৃশ্য নতুন জেনারেট করতে হবে।
- লিংকের ফরম্যাট ভিডিওর মতোই, শুধু শেষে `.jpg` বা `.zip`।
- **সেট:** `deliveries/<YYYY-MM-DD>_set-<নাম>/`। ভেতরে প্রতিটি প্রোডাক্টের ফোল্ডার; সেটের ভিডিও শুধু ক্লায়েন্ট বললে।
- পুরো সেট ও QC প্রস্তুত হলে একবার চূড়ান্ত Git ডেলিভারি; মাঝের প্রতিটি সংশোধনে পুশ নয়।

## নাম ও বিবরণ (লিস্টিং)

- চ্যাটেও প্রতিটি ঘর আলাদা কপি-বক্সে দেওয়া হবে।
