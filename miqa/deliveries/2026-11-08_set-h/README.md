## ১. মডেল-নাম (প্রস্তাব)

**ছাঁচ:** ডায়ালে **ROLEX** লেখা আছে। [`NAMING-AND-DESCRIPTION-GUIDE.md §৩`](../../creative/NAMING-AND-DESCRIPTION-GUIDE.md)
অনুযায়ী — বিখ্যাত ব্র্যান্ডের নাম ঘড়ির নামে/বিবরণে **লেখা যাবে না** (ট্রেডমার্ক + Facebook নীতি)।
তাই নাম হবে **শুধু নতুন নাম + (রঙ)**। ক্লায়েন্ট চাইলে পরে ব্র্যান্ড-নামের সিদ্ধান্ত বদলাতে পারবেন
(সেটে সেটে যা হয়েছে)।

**মডেল-নাম: MONTVARE** — উচ্চারণ মোন্টভেয়ার · *mont* (পাহাড়) + *vare* (সংযত, নিজস্ব) —
ভারী, স্কয়ার, পুরুষালি শব্দ; বাংলায় সহজ।

| বিকল্প | উচ্চারণ | কেন |
|---|---|---|
| **MONTVARE** ⭐ | মোন্টভেয়ার | ভারী, স্কয়ার, পুরুষালি — ডে-ডেট জেম-বেজেলের লুকের সাথে মেলে |
| HALVAREN | হালভারেন | ঠান্ডা, নর্ডিক, স্টিল-টুল ঘড়ির মতো |
| OSTRAVE | ওস্ট্রেভ | ছোট, স্মরণীয়, "ostro" (তীক্ষ্ণ) থেকে |
| CALDREM | ক্যালড্রেম | কঠিন ধাতুর শব্দ, ডার্ক PVD ভ্যারিয়েন্টে ভালো লাগে |

**ওয়েব-চেক (৮ নভেম্বর ২০২৬):** “Montvare”, “Halvaren”, “Ostrave”, “Caldrem” — কোনোটিই
কোনো ঘড়ি-ব্র্যান্ড বা মডেল-নাম হিসেবে পাওয়া যায়নি ✅ (Meridane, Caldren, Corvane, Verdane,
Solmere, Halvren, Castellan, Delvane, Meridiano — এগুলো **পাওয়া গেছে**, তাই বাদ)

> নাম আগে ব্যবহৃত তালিকায় নেই — [NAME-REGISTRY.md](../NAME-REGISTRY.md)-এ যোগ করতে হবে।
