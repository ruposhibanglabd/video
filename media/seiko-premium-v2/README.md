## Reproduce

Use existing npm dependencies and a Python venv with numpy/scipy/Pillow. From repository root, extract the archive's `generated/` and `audio/` into `.tmp/seiko-v2/`, create `.tmp/seiko-v2/render/` and `.tmp/seiko-v2/review/`, then run:

```
.venv/bin/python media/seiko-premium-v2/audio.py
node media/seiko-premium-v2/export.mjs
node media/seiko-premium-v2/qa.mjs
```

Sixteen scene segments total 1,320 frames. Two scenes use the closing watch photograph; no unnecessary lossy re-encode occurs when joining the 4K master segments. The social export is downscaled once with Lanczos. The original procedurally composed underscore is generated by `audio.py` with smooth voice ducking.

The generated source photographs are 768 × 1376; they are upscaled for the 4K master. Graphics and typography are rendered natively at 2160 × 3840. This is not native-4K photographic footage, and generated fine details are not documentary proof of the physical inventory. Facebook can recompress uploaded media.
